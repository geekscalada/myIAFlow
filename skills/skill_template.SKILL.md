# Plantilla de Skill

## Propósito
- Explicar en una frase qué hace el skill y cuándo usarlo.

## Interfaz
- Inputs: parámetros que acepta (p.ej. `text`, `max_tokens`, `language`).
- Outputs: formato del resultado (p.ej. `summary`, `entities`, `table`).

## Requisitos
- Dependencias conceptuales (p.ej. requiere `web_navigator` para obtener HTML).

## Ejemplo
- Input:
  - `{"text":"..."}`
- Output:
  - `{"summary":"...","citations":[...]} `

## Buenas prácticas
- Limitar longitud de entrada, indicar el nivel de detalle, devolver citas exactas.
