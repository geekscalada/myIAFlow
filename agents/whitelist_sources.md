# Lista blanca inicial de fuentes (ejemplos)

Priorizar instituciones, sociedades científicas y revisiones.

- https://pubmed.ncbi.nlm.nih.gov
- https://www.cochrane.org
- https://www.who.int
- https://www.efsa.europa.eu
- https://www.fda.gov
- https://www.aecoc.es (sustituto local ejemplo)
- https://www.semnifer.org (placeholder para sociedades españolas)
- Revistas de alto impacto (Nature, The Lancet, JAMA) — usar con precaución y preferir reviews

Nota: mantener y revisar esta lista periódicamente; añadir dominios de sociedades nacionales relevantes.
